# Session 6 Modular Cognitive Agent

A modular, highly structured, and robust cognitive agent implementing **Perception**, **Memory**, **Decision**, and **Action** layers, executing on strict **Pydantic V2** schema boundaries using **LLM Gateway V3** as the substrate.

---

## 🏛️ Cognitive Layers Architecture

The agent is organized into clean, isolated modules under the `S6/` directory:

1. **`schemas.py` (Contracts)**: Defines all strict Pydantic V2 models for communication between layers.
2. **`perception.py` (Subgoals & State Tracking)**: Decomposes tasks into subgoals, tracks completion states, and triggers the **Force-Attach Safety Net** to attach large fetched artifacts to synthesis and reporting subgoals.
3. **`memory.py` (Durable Fact Extraction & Retrieval)**: Evaluates user queries at the start of a run for newly shared facts, saving them durably under `state/memory.json`. Supports keyword-intersection retrieval.
4. **`decision.py` (Action & Tool Planner)**: Decides whether to invoke an MCP tool or present the final answer. Auto-routes prompts to the `large` gateway tier.
5. **`action.py` (Execution & Artifact Storage)**: Dispatches tool calls to the MCP Server subprocess via Stdio. Output larger than 5,000 bytes is automatically saved to the sandbox's artifact directory as `art:<hex>` to prevent token bloating.

---

## 🛡️ Dual-Layer Structured Output Protection

To completely prevent `503 Service Unavailable` failures during gateway structured output extraction:
- **Zero-Null Schema**: Fields are declared as non-optional types (`str`, `Dict`) with clean defaults (`""` and `{}`), stripping `anyOf` / `null` constraints from the JSON schema.
- **Client-Side Pre-Validators**: Pydantic `@field_validator(mode="before")` decorators capture any drifting `null` / `None` values generated by LLM providers and convert them to safe defaults before Pydantic enforces types.

Ensure your environment variables are configured in `.env` (copied from root directory).

